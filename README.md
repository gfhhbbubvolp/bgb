## 🕹️ Overview

BGB is a highly accurate Game Boy and GBC emulator with a built-in debugger, memory viewer, and VRAM viewer, popular for romhacking and speedrun practice.

Whether you're a newcomer or a veteran, BGB provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
